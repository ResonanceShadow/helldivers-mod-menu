## 🧩 About

**Helldivers Mod Menu** is a curated list of Helldivers open-source tools:

- **Overlays** — on-screen helpers, layout notes, stratagem viewer, loadout switcher
- **Quality-of-Life Helpers** — stratagem catalog, warbond notes, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Stratagem Switcher — quick loadout changes for study
- Show Hitboxes — visualize enemy and hazard hitboxes
- Replay Notes — record and review mission runs
- Playback Speed — adjust solo playback for study (0.1x to 5x)

### Wallhack
- Warbond Catalog — browse armor, capes, and colors
- Custom Loadout Notes — organize player cosmetics
- Visibility Notes — improved marker readability

### Aimbot
- Mission Mode Notes — segment study on any layout
- Hazard Toggle Control — manually toggle hazards in solo study
- Input Buffer Notes — chain complex maneuvers in the editor
